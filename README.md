# Drop Elements

This project implements the `dropElements` function, which removes items from the beginning of an array until one of them satisfies a provided test function.  
It is part of the freeCodeCamp JavaScript curriculum.

---

## Objective

Build a function that:

- Accepts an array (`arr`) and a test function (`func`).
- Iterates through the array **from the first element onward**.
- Removes elements **until** `func` returns `true` for the current first element.
- Returns the remaining portion of the array once the condition is met.
- Returns an empty array if no element satisfies the condition.
